# 📊 Customer Churn Analysis

## 📌 Project Overview

Customer churn is one of the most important challenges for subscription-based businesses. Losing customers directly impacts revenue and long-term growth.

This project analyzes customer data to identify churn patterns, customer behavior, subscription trends, usage patterns, transaction activity, and support-related factors that may contribute to customer churn.

The project combines SQL and Python to perform data extraction, data cleaning, exploratory data analysis, and data visualization.

---

## 🎯 Objectives

- Identify the overall customer churn rate.
- Analyze churn across different subscription types.
- Understand customer usage behavior.
- Analyze transaction and revenue patterns.
- Investigate the relationship between support tickets and churn.
- Identify customer segments with higher churn risk.
- Generate business insights that can help improve customer retention.

---

## 🗂️ Dataset

The project contains multiple related datasets:

- Customer.csv – Customer demographic and account information.
- Customer_usage.csv – Customer usage and activity information.
- Subscriptions.csv – Subscription and plan-related information.
- Support_tickets.csv – Customer support interaction data.
- Transaction.csv – Customer transaction information.

Using multiple related tables allows the project to demonstrate SQL JOINs and relational data analysis instead of relying on a single flat dataset.
